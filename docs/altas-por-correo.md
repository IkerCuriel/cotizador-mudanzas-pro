# Sustitución del alta por correo

El formulario anterior que enviaba solicitudes de perfil al correo del propietario fue retirado. El flujo actual se documenta en [activación comercial](activacion-comercial.md): cuenta verificada → solicitud de perfil en la plataforma → revisión → pago por periodo para negocio aprobado → vigencia confirmada por el servidor.

No se reciben altas mediante un mensaje preparado por correo. Las funciones remotas permanecen desactivadas hasta conectar Supabase, terminar los avisos y habilitar el servicio. Un formulario local no equivale a una solicitud recibida.

El único correo público es **soporte.moveflow@gmail.com**, para asistencia, privacidad y aclaraciones. No se utiliza como credencial, destino automático de pagos ni prueba de titularidad. Las cuentas del propietario en GitHub, alojamiento, Google, Supabase y PayPal conservan sus propias credenciales privadas.
